# Tafqit

Convert any amount to Arabic words with correct grammar, for cheques and invoices. EGP, USD, SAR, AED, KWD, EUR. Offline.

**Live:** https://mostaaafaomran-ctrl.github.io/tafqit/

- Runs fully in the browser, nothing uploaded, no signup
- Plain HTML/CSS/JS, no build step, no dependencies
- Arabic and English

## Run locally
Open `index.html` in a browser.

## Logic tests
`core.js` works in Node: `node -e "console.log(Object.keys(require('./core.js')))"`
